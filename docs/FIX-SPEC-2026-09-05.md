## 2 · כל עמוד מוגש בשתי כתובות עם 200 🔴

**הממצא — נמדד חי בפרודקשן ב-05/09/2026:**

```
https://eliavafar.co.il/contact         -> 200
https://eliavafar.co.il/contact.html    -> 200
https://eliavafar.co.il/index.html      -> 200
https://eliavafar.co.il/earthworks.html -> 200
```

שתי הכתובות מחזירות תוכן מלא, אף אחת לא מפנה לשנייה.

**ובמקביל:** ה-`canonical` בכל עמוד מצביע על הגרסה **הנקייה** (`<link rel="canonical" href="https://eliavafar.co.il/contact">`), אבל **כל הקישורים הפנימיים באתר מצביעים על גרסת ה-`.html`**:

| קישור | מופעים |
|-------|--------|
| `../index.html` | 85 |
| `../contact.html` | 78 |
| `index.html` | 68 |
| `../bentonite-drilling.html` | 68 |
| `../earthworks.html` | 67 |
| `../drainage-pits.html` | 65 |
| `../equipment-rental.html` | 60 |
| `contact.html` | 57 |

**התוצאה:** גוגל מקבל שני URL תקינים לכל עמוד, וכל ה-internal linking מזרים סמכות לכתובת ש-canonical עצמו מכריז שאינה הקנונית. זה הפער הטכני הגדול ביותר באתר.

**התיקון — שני שלבים, בסדר הזה:**

**שלב א' — 301 מ-`.html` לנקי.** ב-`vercel.json`, בתוך מערך `redirects` הקיים (יש שם כבר 301-ים לכתובות בעברית — להוסיף באותו פורמט):

```json
{ "source": "/:path*.html", "destination": "/:path*", "statusCode": 301 }
```

⛔ **חובה לבדוק לפני דחיפה** שזה לא מתנגש עם `middleware.js` ולא שובר את הגשת ה-Markdown. אחרי הדפלוי: `npm run check-agentic` חייב לחזור 100, ו-`curl -I https://eliavafar.co.il/contact.html` חייב להחזיר 301 ולא 200.

**שלב ב' — כתיבה מחדש של הקישורים הפנימיים.** כל `href="X.html"` ו-`href="../X.html"` ← הכתובת הנקייה המקבילה:

- `index.html` / `../index.html` ← `/`
- `contact.html` / `../contact.html` ← `/contact`
- וכן הלאה לכל שאר העמודים.

⚠️ **לא לגעת** בקישורים חיצוניים, ולא ב-`src` של ה-`iframe` (`src="drainage-calculator.html"` ב-`drainage-pits.html:420`) לפני שווידאת שהוא נטען מהכתובת החדשה.
⚠️ הבלוג יושב בתיקייה נפרדת — לוודא שהיחסיות (`../`) לא נשברת במעבר לכתובות מוחלטות.

**אימות:** אחרי הדפלוי — `grep -rn 'href="[^"]*\.html"' --include=*.html . | grep -v node_modules` צריך לחזור ריק (למעט חריגים מודעים), ו-`npm run check-site` ירוק.

**המרות לא נמדדות בכלל.** ב-GA4 לא סומנו Key Events, ו-Google Search Console לא מקושר ל-GA4. המשמעות: כל התיקונים במסמך הזה יבוצעו **בלי יכולת למדוד אם הם עזרו**. זו משימה של 10 דקות לבעל האתר, והיא צריכה לקרות **לפני** גל התיקונים ולא אחריו.

נתוני בסיס שנמדדו ביולי 2026, לצורך השוואה עתידית: 717 צפיות ב-Google Business Profile ← 99 אינטראקציות ← 9 שיחות ← **4 ביקורים באתר**.
